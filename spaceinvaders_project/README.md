# Space Invaders Java Project

A Java-based course project where I practiced object-oriented programming, debugging, collision detection, UI handling, and gameplay feature development.

## Overview

This project was based on a Space Invaders-style game. I extended and modified the project by adding gameplay features, improving game logic, and practicing clean object-oriented code structure.

## My Contributions

- Added and modified collision detection functionality
- Worked on player controls and enemy behavior
- Added UI and game-state handling, including menus and gameplay screens
- Implemented difficulty and gameplay adjustments
- Practiced debugging and organizing code within an existing codebase
- Used GitHub and GitKraken for version control

## Skills Used

- Java
- Object-Oriented Programming
- Debugging
- Collision Detection
- UI / Game-State Logic
- GitHub
- GitKraken
