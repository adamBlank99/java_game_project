# Java Space Invaders Project

A Java-based Space Invaders-style course project where I practiced object-oriented programming, debugging, collision detection, UI handling, and gameplay feature development.

## Overview

This project was built as part of a school course and extended with additional gameplay features and improvements. My work focused on modifying and improving game behavior, organizing logic within an existing codebase, and using object-oriented programming principles to support multiple gameplay systems.

## Features

- Collision detection for player, enemy, and projectile interactions
- UI and game-state handling for gameplay screens
- Difficulty settings and gameplay adjustments
- Parallax background effects
- Shooter ability system with cooldown and duration tracking
- Boss enemy behavior and gameplay-state updates
- Version control using GitHub and GitKraken

## My Contributions

- Worked on UI handling and game-state updates
- Implemented difficulty and gameplay improvements
- Created shooter-type ability logic using object-oriented programming
