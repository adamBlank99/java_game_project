# Java Space Invaders Project

This started as base code from a TXST course project as a Java Space Invader Style game with very basic enemy and player functionality. I used object-oriented programming practices to add many features such as: different pilot classes, a boss enemy, menu screens (main, pause, game over, class selection), enemy wave spawning based on level, hp tracking, parallax background, and more.

## Overview

This project was built as part of a school course and extended with additional gameplay features and improvements. My work focused on modifying and improving game behavior, organizing logic within an existing codebase, and using object-oriented programming and debugging to support multiple gameplay systems.

## My Contributions

- Added and modified collision functionality
- Worked on UI handling and game-state updates
- Implemented difficulty and gameplay improvements
- Created shooter-type ability logic using object-oriented programming
- Boss enemy behavior and gameplay-state updates
- Parallax background effects
- Shooter ability system with cooldown and duration tracking
- Practiced debugging, code organization, and feature development within an existing project structure
- Used GitHub and GitKraken to organize files and track changes

## Skills Used


- **Java & Swing:** Built the game using Java Swing, JPanel rendering, keyboard listeners, and event-driven UI logic.
- **Object-Oriented Programming:** Used classes for players, enemies, bullets, shields, menus, and background systems.
- **Design Patterns:** Applied listener/observer behavior through Swing events, state-based screen management, and strategy-style player abilities.
- **Game Systems:** Implemented collision detection, enemy spawning, boss behavior, level progression, score tracking, and lives.
- **Rendering:** Created custom `Graphics2D` rendering, custom sprites, UI overlays, and a parallax particle background.
- **Version Control:** Managed the project using Git, GitHub, and GitKraken.
